2.1 What is Deep Learning?

Deep Learning is a part of Machine Learning that uses Artificial Neural Networks with many layers to learn complex patterns from data.

Machine Learning Deep Learning
Often needs manual feature engineering Can learn features automatically
Can work well with small to medium datasets Usually needs much more data
Many traditional algorithms Neural networks with many layers
Training is relatively light May need a GPU

Example uses:

  • Face recognition.
  • Speech recognition.
  • Image classification.
  • Natural Language Processing.
  • Generative AI and LLMs.

2.2 Neural Network

A neural network is inspired by how biological neurons work.

Basic structure:

  1. Input Layer: receives the data.
  2. Hidden Layers: learn the patterns.
  3. Output Layer: produces the prediction.

Each neuron performs the operations:

z=Wx+bz = Wx + bz=Wx+b

a=f(z)a = f(z)a=f(z)

Where:

  • xxx: input.
  • WWW: weights.
  • bbb: bias.
  • fff: activation function.
  • aaa: neuron output.

2.4 Forward Propagation and Backpropagation

Forward Propagation: data moves from the input to the output to produce a prediction.

Backpropagation: the model computes how the error affects each weight and bias, using the chain rule from calculus. The optimizer then updates the model parameters to reduce the error.

The training cycle:

  1. Forward pass: compute the prediction.
  2. Compute the loss.
  3. Backward pass: compute the gradients.
  4. Optimizer step: update the parameters.

2.5 Loss Function

A loss function measures how far the model's prediction is from the true value.

Loss Use
MSE Regression
MAE Regression
Binary Cross Entropy Binary classification
Categorical Cross Entropy Multiclass classification
Huber Loss Regression that is more robust to outliers

2.6 Optimizer

An optimizer determines how the model parameters are updated.

The most important ones:

  • SGD (Stochastic Gradient Descent)
  • Momentum
  • RMSprop
  • Adam
  • AdamW

Adam and AdamW are often used as the first optimizer for deep learning. The choice of optimizer should still be tested against the model and the dataset.
