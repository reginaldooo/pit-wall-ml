TensorFlow and Keras

TensorFlow and Keras

Estimate: 2 hours≈ 2 min read

Prerequisites: PyTorch

5.1 What is TensorFlow?

TensorFlow is a Machine Learning and Deep Learning framework from Google for training, deployment, and production ML.

TensorFlow has a high-level API called Keras that makes building neural networks easier.

5.2 Building a Neural Network with Keras

import tensorflow as tf
from tensorflow import keras

model = keras.Sequential([
    keras.layers.Input(shape=(10,)),
    keras.layers.Dense(64, activation="relu"),
    keras.layers.Dense(32, activation="relu"),
    keras.layers.Dense(1)
])

model.compile(
    optimizer="adam",
    loss="mse",
    metrics=["mae"]
)

model.fit(
    X_train,
    y_train,
    epochs=100,
    batch_size=32,
    validation_data=(X_val, y_val)
)

5.3 Evaluation and Prediction

results = model.evaluate(X_test, y_test)

predictions = model.predict(X_test)

5.4 PyTorch vs TensorFlow

Aspect PyTorch TensorFlow/Keras
Language Python Python
Model building nn.Module Keras API
Training Manual training loop is common model.fit()
Autograd Built-in GradientTape
Flexibility Very flexible Flexible
Deployment TorchServe and other ecosystems TF Serving, TFLite, and others
Research Very popular Also used

Which should you learn first?

Recommendation: learn PyTorch first, then understand Keras/TensorFlow at a basic level.

PyTorch helps you understand the training process explicitly, including gradients, backpropagation, and the optimizer. Once you understand the concepts, switching frameworks is easier.
