6.1 Linear Algebra

b = np.array([4, 5, 6])

6.2 Calculus

Calculus is needed to understand how a model learns.

A. Derivative

f′(x)=dfdxf'(x)=\frac{df}{dx}f′(x)=dxdf​

Measures how a function changes when the input changes.

B. Partial Derivative

∂L∂w\frac{\partial L}{\partial w}∂w∂L​

Measures how the loss changes with respect to one specific parameter. This is very important in neural networks.

C. Chain Rule

dLdx=dLdy×dydx\frac{dL}{dx}=\frac{dL}{dy}\times\frac{dy}{dx}dxdL​=dydL​×dxdy​

Used in backpropagation.

D. Gradient

∇f(x)=[∂f∂x1∂f∂x2]\nabla f(x)= \begin{bmatrix} \frac{\partial f}{\partial x_1}\\ \frac{\partial f}{\partial x_2} \end{bmatrix}∇f(x)=[∂x1​∂f​∂x2​∂f​​]

The gradient shows the direction of the greatest increase of a function.

6.4 Optimization

Optimization is the process of finding the best parameters to minimise the loss function.

Gradient Descent

wnew=wold−α∇L(w)w_{new}=w_{old}-\alpha\nabla L(w)wnew​=wold​−α∇L(w)

Where:

  • www: the model parameters.
  • α\alphaα: the learning rate.
  • ∇L\nabla L∇L: the gradient of the loss.

Learning Rate

  • Too large: training can become unstable.
  • Too small: training can be very slow.

Metric Formula Use
Accuracy TP+TNTP+TN+FP+FN\frac{TP+TN}{TP+TN+FP+FN}TP+TN+FP+FNTP+TN​ Classification

Where:

  • TP: True Positive.
  • TN: True Negative.
  • FP: False Positive.
  • FN: False Negative.

Fintech example:

In fraud detection, accuracy is not always the best metric.

For example:

  • 99% of transactions are normal.
  • 1% of transactions are fraud.

A model that always predicts a normal transaction can reach 99% accuracy, yet fail to detect any fraud.

That is why precision, recall, F1-score, PR-AUC, and the cost of prediction errors need to be considered.
